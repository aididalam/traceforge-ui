# TraceForge UI

Part of [TraceForge](https://github.com/aididalam/traceforge). See the parent repository for setup and deployment.

Provides the Next.js business dashboard and public product tracking interface.
Businesses register, add products, scan codes and request receipt from holders.
The Receipt requests page shows requester Organization IDs/wallets and supports
bulk approval, decline and cancellation. Confirmed receipts update inventory.
Customers view shared product details, current holders and dated supply history.
